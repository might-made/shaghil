# SHAGHIL — Pilot Scorecard

**Status: DAY 1A FOUNDATION — FOUNDER REVIEW REQUIRED**
**Mode: Documentation-only. This is a blank template — no pilot data exists yet.**

This scorecard operationalizes the evidence collection defined in `SHAGHIL_NATIONAL_PRODUCT_READINESS_MASTER.md` §07 and is completed once per pilot participant, per `SHAGHIL_CLOSED_PILOT_PLAN.md` §5.

**Privacy note:** Use a participant ID, never a full name, phone number, email, or business-identifying detail beyond what is listed below. Do not record more personally identifiable information than this template specifies. Testimonial permission and follow-up contact details, if given, should be stored separately from this scorecard, not inline with usage data.

## Usage Notes

- Complete this during or immediately after the participant's real-task session (§4 of the Closed Pilot Plan), while detail is fresh.
- "Failed/confusing moments" and "Biggest problem" are the most valuable fields for the P0/P1 triage described in Master §10 — do not skip or shorten these to save time.
- Aggregate all Wave 01 scorecards for the Days 6–7 evidence review (Master §09) before any Wave 02 decision.
- This template itself may be refined between waves based on what proves useful or missing — any such change is a documentation update, not a runtime change, and should be noted with a date and reason if made.
